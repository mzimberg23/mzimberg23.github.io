# Nursing e-Portfolio

This repository contains a simple professional nursing e-Portfolio website built with basic HTML, CSS, and optional JavaScript. It is designed for a nursing student preparing to apply for positions after earning a BSN.

## Files

- `index.html` — main portfolio page with welcome, resume, cover letter, and recommendation request sections.
- `styles.css` — site styling with responsive layout and print-friendly formatting.
- `script.js` — optional mobile navigation toggle.

## How to view locally

1. Open the folder in VS Code.
2. Open `index.html` in the browser using the Live Server extension or by double-clicking the file.

## How to publish with GitHub Pages

1. Create a GitHub repository for this project.
2. Commit and push all files to the repository.
3. In the repository settings, enable GitHub Pages from the `main` branch and set the source to `/ (root)`.
4. After a few moments, the site will be available at `https://<username>.github.io/<repository-name>/`.

## Customization

Update the placeholder text in `index.html` before publishing:

- `[Name]`
- `[Email]`
- `[Phone]`
- `[School]`
- `[Graduation Date]`
- `[Employer Name]`
- `[Facility Name]`
- `[Position Title]`
- `[Recipient Name]`
- `[Recipient Role]`
- `[Date]`
- `[Deadline Date]`

## Notes

- The design is intentionally clean and professional.
- The resume, cover letter, and recommendation request are formatted for both screen and print.
- No paid libraries or frameworks are used.
